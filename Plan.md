# План: программа `md-img-local.py`

План *Big Pickle*.

**Язык:** Python, зависимости: `requests` (стандарт проекта — `uv`).

## CLI
```
python download_images.py <файл.md> [--media каталог]
```
- `<файл.md>` — единственный обязательный аргумент.
- `--media` — каталог для картинок, по умолчанию `media/` рядом с файлом.
- Флаг `--no-backup` (опционально) — пропустить создание `.orig`.

## Алгоритм

1. **Резервная копия**: `файл.md` → `файл.md.orig` (конвенция уже используется в заметках). Если `.orig` уже существует — перезаписать (обновить).

2. **Сбор ссылок** (три синтаксиса):
   - Inline: `![alt](<url> | url "title")`
   - Reference-style: `[id]: <url>` — сначала собрать определения ссылок в словарь, затем находить `![alt][id]` и подставлять URL; `[id]: url` в итоге удаляется из результата.
   - Инлайн-HTML: `<img src="url" ...>` (атрибут `src`, с учётом одинарных/двойных кавычек).

3. **Скачивание** в `media/` с дедупликацией:
   - Имя: `stem-<sha256(url)[:10]><ext>` (как в `remote images to local-gpt.md`).
   - Расширение: из URL → иначе `Content-Type` → иначе `.bin`.
   - Одинаковый URL в любом из трёх синтаксисов — скачивается один раз (общий кэш URL→путь).

4. **Замена ссылок** на `media/файл` (posix-слэши, путь относительно файла .md):
   - inline: `![alt](media/файл "title")`
   - reference: заменяется на inline `![alt](media/файл)`, определение удаляется
   - `<img src="media/файл">`
   - Локальные пути (`./`, `media/`, файл без схемы) не трогаются.

5. **Обработка ошибок**: сбой скачивания — `[ERROR] url: причина`, ссылка остаётся как была; обработка продолжается.

6. **Запись**: результат пишется в исходный `файл.md` (после успешного полного прохода). В stdout — отчёт: найдено/скачано/не удалось, путь результата.

## Проверка
- Проверка: локальные ссылки не тронуты, дубликаты URL не качаются повторно.
